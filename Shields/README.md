# Shields for the KinetiX main board

These are electronic boards that can be added on top of the main KinetiX board to extend its capabilities.

It takes advantage of the pins mounted on the main board to access the GPIOs of the ESP as well as the power line of the servos.

More information about the shields in the wiki:
