The EASYEDA_PCB_BASE_ShieldV0.1.json file can be imported in online PCB editor EasyEda.com to make a new PCB with specific component implantation.

It ensures the dimensions fit the KinetiX main board.

If the servo power lines are not needed the top area can be freed to make more room for more components.
