# The labShield PCB

In this directory you will find the Gerber file you can upload to any PCB maker to have the PCB made.

The JLCPCB_PCB_LabShield.json file is the source file for this PCB, that can be used with online editor https://easyeda.com/
to modify it and generate a new Gerber file.
