# The Lab Shield


The purpose of the lab shield is to offer an easy protoyping platform to test your ideas about sensors, monitoring, etc.
It's a simple board that can be mounted on the main KinetiX board and exposes the ESP32 GPIOs as well as the servomotors 
power supply line.

It is equipped with many pads to solder extra components, but does nothing in itself.

Once an idea is tested and tweaked using this shield, a new specific PCB can easily be made from the same source files.

> [!CAUTION]
> This is a work in progress, the PCB has not been tested yet.
