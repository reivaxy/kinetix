Apple does not allow building an application that could be easily uploaded to a phone outside of the Apple ecosystem,
so you need the development environment to install the application on your phone.

So if you can do it, this folder contains a basic application that allows to control the KinetiX device with your 
iPhone by tapping the buttons on the screen. There is not voice control yet, no firware settings edition, and no firmware OTA update,
but if someone wants to implement any of these, feel free to fork and create a PR!

For iPhone users who can't do it, here is an easy alternative: install the Chrome browser on your iPhone (because Safari can't do this) 
and open this page: https://reivaxy.github.io/kinetix/

You will have a single page application to connect to the KinetiX, send it orders, access its parameters, and update the firmware wirelessly.
