Apple does not allow building an application that could be easily uploaded to a phone outside of the Apple ecosystem 
(App store), so you need the install development environment to install this application on your phone.

> [!WARNING]
> This application is now obsolete, it does not allow viewing and editing the firmware settings, and it does not allow upgrading the firmware.
 
If you have the development environment, this folder contains a basic application that allows to control the KinetiX 
device with your iPhone by tapping the buttons on the screen. There is no voice control, no firware settings edition, and no firmware OTA update, but if someone wants to implement any of these, feel free to fork and create a PR!

> [!TIP]
> I recommand this alternative solution:

For iPhone users who can't do it, here is an easy alternative: install the Chrome browser on your iPhone (because 
Safari can't do this) and open this page: https://reivaxy.github.io/kinetix/

You will have a single page application to connect to the KinetiX, send it orders, access its parameters, and update the firmware wirelessly.

This webpage application is maintained and will be updated with new features.
