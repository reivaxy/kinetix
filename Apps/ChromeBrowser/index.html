Bluetooth BLE control interface for the KinetiX hand

Requires Chrome/Edge with Web Bluetooth, served over https or http://localhost.
Not all computers have Bluetooth BLE connectivity.
This does not work on iOS devices because Apple does not implement BLE access in webkit.
This page only exchanges information with your KinetiX device. No cookie, no server call. You can run a local server and access it through http://localhost

Finger tuning
Depending on the wire tensions, these settings might help adjusting the opened and closed positions of each finger.
To adjust max open positions, set the hand to position "Five" (fully open).
To adjust max closed positions, set the hand to position "Fist" (fully closed).
⚠ Warning: Proceed with caution when modifying position values to avoid excessive strain on the servo motors. Fingers 2 and 4 are in opposite direction so their settings are reversed
Each field is written immediately when changed.
