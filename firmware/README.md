# Software

Folder esp32 contains the actual software for the Seeed Studio XIAO ESP32S3

Beware, it won't work with the Seeed Studio XIAO ESP32C3 (C3 vs S3), some modifications would be required in the servomotor command.

You can find some information about installing the firmware in the wiki: 

https://github.com/reivaxy/kinetix/wiki/05.-Firmware

And some explanation about the code itself:

https://github.com/reivaxy/kinetix/wiki/05.-Firmware#the-code


Folder rp2040 contains preliminary tests with an early prototype on breadboard, and is no longer maintained.
